# CleanDrop

A fast, zero-dependency directory organizer and automated file triage utility written in Python.

## ✨ Features
- **Zero Dependencies**: Runs out of the box with standard Python 3 libraries.
- **Smart Classification**: Categorizes files into Images, Videos, Audio, Documents, Archives, and 3D Models.
- **Safe Execution**: Automatically ignores system files, hidden files, and self-scripts.

## 💻 Usage
Run the script directly and provide the target path (or leave blank for the current folder):

```bash
python3 cleandrop.py
